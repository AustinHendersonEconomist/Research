# Health Economics, Interactive

Nine-chapter course companion (Chapter 9: value of information). Each chapter ends with a fixed-seed classroom run in Health of Nations (`?assignment=a1`…`a9`); the course also ships inside the game build at `/course/` — https://austinhendersoneconomist.github.io/health-of-nations-play/course/ once deployed. `hub.html` is the artifact main page (body fragment); chapter pages are standalone documents. Published: https://claude.ai/artifact/NxJnaBv1jGrJXHSaYeZaBv

To host elsewhere, wrap `hub.html` in a standard HTML document and save it as `index.html`.
